Make your credits

Shoutout without code, for Framer, Webflow, Squarespace, Wix and other site builders.

Fill in who made what. You’ll get one snippet to paste into your site, and a Shoutout button appears in your footer.

Your snippet

Paste it where your site builder lets you add code to every page, at the end of the body:


  

    
    
  

  


  
Where to paste it

  

    
Framer
Site Settings, General, Custom Code: End of <body> tag.

    
Webflow
Site settings, Custom code: Footer code. To light up a part exactly, select it, then Element settings, Custom attributes: name data-credit, value the credit’s id shown above its fields.

    
Squarespace
Settings, Advanced, Code Injection: Footer. Custom code needs a paid plan.

    
Wix
Settings, Custom Code: add it to all pages, in the Body, end. Custom code needs a paid plan.

    
Anything else
Wherever it lets you add HTML to every page. If it can host files, you can upload credits.json and use the shorter version you get with “Download credits.json instead”.

  


  
Pointing at the right part

  
Site builders don’t let you name things the way code does, so tell Shoutout how to find the part: a picture by a word in its file name or its alt text, or anything by its class or id (your builder shows these in its settings or in the browser’s “Inspect”). Leave it on “Nothing on the page” for a tool you made the site with, or a font used everywhere: it’s listed at the bottom instead.
