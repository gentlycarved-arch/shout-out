Flowers

Give the makers their flowers. A Credits button for any website. Press it (at the bottom of the page) and the page fades away, except for the parts made with other people's free tools, which glow, each with its title. Hover one to see who made it.

Tagged by selector

These icons are credited with a CSS selector in credits.json, so the markup didn't need changing.

Tagged by attribute

The gradient above has data-credit="aurora" on its canvas.

Replayed motion

This button's hover comes from someone else's snippet. With Credits on, it plays by itself, slowly, so you can see it.

Listed only

The typeface is everywhere, so it sits in the list without a highlight.

Add it to a site

<link rel="credits" href="/credits.json">
<script src="flowers.js" defer></script>

<img src="hero.webp" data-credit="aurora" alt="…">

The credits on this page are made-up examples. The format is in SPEC.md.
